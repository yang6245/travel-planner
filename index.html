关于 Token
• 普通访客无需配置 Token，可直接只读查看行程
• 只有管理员编辑行程时才需要配置 Token（用于写入 GitHub 仓库）
• Token 只保存在当前浏览器中，不会上传到任何服务器
Token 以 ghp_ 开头，获取方式见下方说明
如何获取 Token？
1. 打开 https://github.com/settings/tokens/new
2. Note 填 "travel-planner"
3. Expiration 选 "No expiration"（永不过期）
4. 勾选 repo 权限（整个 repo 组）
5. 点击底部绿色按钮 "Generate token"
6. 复制生成的 Token 粘贴到上方输入框
